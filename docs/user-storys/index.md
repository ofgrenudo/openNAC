# User Stories

How a client moves between network access levels, and how a device gets
registered or upgraded to the secure network.

Everything here falls under one of two registration policies — [Optional Registration](optional-registration) (unregistered devices still get working access) or [Mandatory Registration](mandatory-registration) (no access until registered) — plus a handful of stories that apply either way: [Secured VLAN Access](secured-vlan-access), [Device Offboarding](device-offboarding), [MAC Randomization Recovery](mac-randomization-recovery), [Optional Self-Registration Expiry](self-registration-expiry), and [DB-Down Fail-Safe](db-down-failsafe).
